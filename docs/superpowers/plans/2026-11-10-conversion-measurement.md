# 데이밋 전환 계측 구현 계획

사용자가 승인한 보고서 분석을 바탕으로 첫 제출과 생성 이후 퍼널을 측정한다. 기존 화면 디자인은 유지한다. 익명 작성자 수정과 공유 화면 변경은 계측 이후 별도 작업이다.

## 구현 범위

1. 공통 이벤트와 안전한 메타데이터, 브라우저 방문 식별자, 유입 문맥, 측정 선택을 구현한다.
2. 생성과 응답 저장의 서버 확정 결과를 구분하고 최초 제출 시각과 그룹 활성화를 기록하는 마이그레이션을 추가한다. 과거 빈 응답을 제출로 추정하지 않는다.
3. 폼 진입, 이벤트 열람, 편집 시작, 복사 성공, 저장 실패를 계측하고 실제 성공에만 전환을 연결한다.
4. 공식 OpenAI Measurement Pixel과 Conversions API 규격에 맞춘 어댑터를 환경변수로 제어한다. 공개 Pixel ID와 서버 API 키를 분리하고 같은 전환 ID를 재사용한다. 미설정과 개발 환경에서는 외부 전송하지 않는다.
5. 새 GA4·OpenAI 전환 데이터에는 이름, 제목, 비밀번호, 시간표 원문, 실제 접근 링크를 포함하지 않는다. 전환 측정 선택과 철회를 이 전송에 반영한다. 기존 Clarity 녹화·히트맵은 별도 프로젝트 ID로 유지하며 이 전환 계측 스위치나 선택으로 끄지 않는다. 실제 페이지 경로 수집과 DOM 마스킹의 차이를 문서화한다.
6. 환경변수 예시, 설정 절차, 보고 지표, 컴포넌트 관계 맵과 변경 기록을 갱신한다.

## 검증

먼저 유입 정제, 허용 이벤트, 중복 방지, 비활성 환경과 공식 광고 전송 규격의 실패 테스트를 작성한다. 구현 후 타입체크와 전체 npm run verify를 실행한다. 새 린트 억제나 의존성을 추가하지 않는다. 독립 코드 리뷰에서 보안과 저장 성공 판정, 광고 비밀키 노출 여부를 확인한다.

프로덕션 마이그레이션 적용은 AGENTS.md에 따라 사람이 수행한다. 광고 계정과 캠페인 설정은 변경하지 않는다.
